# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Fully specified for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use these labels for the skills' triage roles, not as implementation states. A
triaged issue should have exactly one state-role label and one category label
(`bug` or `enhancement`). Flag conflicting state-role labels before changing
them. Rejection is not successful delivery.

# Static views

Use [`twig show 12345`](../context/show.md) for item detail and
[`twig tree 12345`](tree.md) or `twig show 12345 --tree` for a targeted ADO hierarchy.
For named Bench membership, use [`twig workspace --bench MyWork`](../workspace/workspace.md).
To refresh that view, run `twig workspace --bench MyWork --refresh`.

These are static CLI projections. The sprint/team/full-backlog/live views,
`tree --all`, and old browser/TUI are retired. GitHub tree presentation is not
qualified. The separate [server](../../server.md) owns its graphical host contract.

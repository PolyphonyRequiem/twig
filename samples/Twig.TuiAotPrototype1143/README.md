# Archived TUI prototype evidence

Only the recorded `evidence/` artifacts are retained. The non-solution
executable/source-linked prototype, launchers and Herdr manifest were removed
when the full-screen TUI integration was retired. These captures are historical
research, not a buildable sample or current qualification.

The supported sample is `samples/Twig.DetailHost`, a .NET 10 consumer of the
public RenderTree SDK.

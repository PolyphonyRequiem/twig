# Shell prompt integration: retired

`twig ohmyposh init` and the old `.twig/prompt.json` shell-presentation contract
are retired. Do not install the old hook or rely on its sample configuration as
a supported current integration.

This is separate from **OMP (Oh My Pi) agent skills**, whose explicit installation
and companion selection are described in [installed help and skills](features/skills.md).
An OMP package does not restore retired CLI rendering envelopes.

Use `twig show <id>` or `twig workspace` for current static terminal reads.
See the [command reference](commands/README.md) for supported routes.

# CLI commands

`Twig` is a source-generated ConsoleAppFramework executable. Public registered
declarations determine the finite command catalog, option syntax and defaults.
Bundled `docs/commands/index.json` and current Markdown provide behavior/effects/
failures/examples; they must not advertise removed routes.

Offline version/help/skills return without work-item I/O. Argument, output and
structured-target checks run before provider/workspace/input effects.
No-marker data calls require fresh init, not legacy DI fallback.

Current handlers use Core/native composition. Structured mutations require an
explicit target; static human rendering does not invent machine scope.
Errors remain nonzero and unavailable/unsupported/indeterminate outcomes stay
distinct from empty success.

The command layer does not own provider policy, journals or a second publisher.
Use source-generated JSON for AOT, declared output formats, and telemetry's
strict identifier/content allowlist. Retired captured UI envelopes and
presentation-only options are not hidden compatibility routes.

See the [current command reference](../commands/README.md) and
[development skill](../../.github/skills/twig-command-dev/SKILL.md).

# ADO integration

`Twig.Providers.Ado` implements qualified ADO discovery, observations and effects
behind Core ports. Native Infrastructure admits the exact enrolled identity,
binding and source; provider selection cannot fall through to an ambient
account or legacy REST client graph.

Discover work-item types, states, transitions, fields, allowed values and close
gates from the connected process. No process-template-specific vocabulary is a
generic product rule. Unknown schema/rules remain explicit gaps and can block
publication.

Core proposals bind typed intent to exact identity, schema, store/policy and
revision evidence. Native execution and readback establish outcomes; hosts do
not duplicate policy or add publishers. Coupled state/close-gate fields share
one batch operation. Qualified ADO editor, seed-chain, navigation/tree and sync
support does not imply equivalent GitHub capabilities.

See [authentication](../features/authentication.md),
[current proposals](../features/proposals.md) and the
[provider boundary](provider-contract-boundary.md).

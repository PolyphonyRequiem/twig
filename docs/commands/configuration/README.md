# configuration commands

Current bundled command behavior. Executable help supplies declaration-derived syntax.

| Command | Behavior |
|---|---|
| [`skills install`](skills-install.md) | Install the generic Twig skill family into an explicit root. |
| [`skills update`](skills-update.md) | Update unedited Twig-owned guidance while preserving companions. |
| [`skills configure`](skills-configure.md) | Select or clear an additive companion for one provider and scenario. |
| [`skills status`](skills-status.md) | Inspect installed guidance identity, integrity and bounded discovery. |
| [`skills add`](skills-add.md) | Install one separately supplied integration or variant skill. |

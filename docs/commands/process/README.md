# Process and schema

| Command | Purpose |
| --- | --- |
| [`process`](process.md) | List discovered type references |
| [`process <type>`](process-type.md) | Fields, states, rules and gaps for an explicit discovered type |
| [`process description`](process-description.md) | Structured acquired Core schema, full or compact |
| [`states`](states.md) | Human active-item convenience only; scripts use an explicit type |

The current descriptor is `core-schema-1`, not a complete native form/layout or
workflow export. `process layout` is retired.
See [process evidence and gaps](../../features/process-description.md).

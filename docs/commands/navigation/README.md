# navigation commands

Current bundled command behavior. Executable help supplies declaration-derived syntax.

| Command | Behavior |
|---|---|
| [`nav up`](nav-up.md) | Navigate to the parent work item. |
| [`nav down`](nav-down.md) | Navigate to a child work item. |
| [`nav next`](nav-next.md) | Navigate to the next sibling work item. |
| [`nav prev`](nav-prev.md) | Navigate to the previous sibling work item. |

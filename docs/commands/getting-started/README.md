# Initialize and refresh

| Command | Effect |
| --- | --- |
| [`init`](init.md) | Create a fresh pinned Core store; no backlog prefill or old-state adoption |
| [`workspace --bench MyWork --refresh`](../workspace/workspace.md) | Pull permitted members of an explicit Bench without saving drafts |

Use the [setup guide](../../getting-started.md) before the per-command reference.
For a single provider item, use `twig show <id> --refresh`.

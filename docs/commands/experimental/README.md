# Retired integrations

The old [`tui`](tui.md), [`mcp`](mcp.md), and
[`ohmyposh init`](ohmyposh-init.md) launch/integration paths are retired,
not optional supported companions.

The separately installed Windows daemon has its own
[read-only MCP interface](../../daemon.md#read-only-mcp). It does not restore the
old mutation server, TUI aliases, or shell hooks.

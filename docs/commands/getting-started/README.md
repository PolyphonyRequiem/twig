# Initialize and synchronize

| Command | Effect |
| --- | --- |
| [`init`](init.md) | Create a fresh pinned Core store; no backlog prefill or old-state adoption |
| [`sync`](sync.md) | Can save existing-item drafts before pulling selected Bench scope |
| [`refresh`](refresh.md) | Deprecated pull-only alias; no draft flush |

Use the [setup guide](../../getting-started.md) before the per-command reference.
Select a Bench explicitly before sync. No GitHub sync convenience is qualified.

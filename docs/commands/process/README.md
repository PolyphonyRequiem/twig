# process commands

Current bundled command behavior. Executable help supplies declaration-derived syntax.

| Command | Behavior |
|---|---|
| [`process`](process.md) | Show process configuration: list types (no args) or type details (with type name). |
| [`process description`](process-description.md) | Describe the admitted provider's Core schema (core-schema-1), with explicit scope and presentation gaps. |
| [`states`](states.md) | Human-only alias for the active work item's states; structured callers must use process &lt;type&gt;. |

# Read, find, and select

| Command | Purpose |
| --- | --- |
| [`show`](show.md) | Cached detail; explicit `--refresh` for provider acquisition |
| [`show-batch`](show-batch.md) | Multiple cached numeric targets, missing IDs disclosed |
| [`query`](query.md) | Bounded provider query using actual schema |
| [`set`](set.md) | Human active-item selection, not assignment or a claim |

Structured reads need explicit targets. GitHub does not qualify human active
selection, trees, navigation, or all ADO query predicates. See
[provider differences](../../getting-started.md#provider-differences).

`history`, `tree-set`, and `web` are retired; no legacy cache route is available.
